# 각 주제에 맞는 사진 이름 (representative_image_name)
- 음식 이름, 영양 성분 이름, 영양제 이름, 슈퍼 푸드 이름, 섭취 가능한 것, 몸에 도움이 되는 것 등 단 하나의 이름 명시
- 각 주제에 해당하는 사진을 넣어 블로그를 만들려는 용도.

# 필수 주제
- 1. 질문에 대한 심층 답변
- 2. 추천 식품
- 3. 추천 영양제

# 주제 개수
- 주제는 request 이다
- 필수 주제는 모두 나와야 하고 1~2 개의 필요에 따라 기타 주제를 추가한다
- 그래서 총 주제 개수는 4~5 개 (size(request) = 4~5)

{information}

# 출력 규칙 (중요)
1) 반드시 JSON으로 출력.
2) 출력은 반드시 다음 최상위 키를 포함한다: "request"
3) 입력 {information} 안의 request 템플릿을 그대로 사용한다:
   - request는 list이며 길이는 고정이 아니다(여러 개 가능). 반드시 입력 request의 길이와 동일하게 출력한다.
   - 각 request[i].subject 역시 list이며 길이는 고정이 아니다. 반드시 입력 request[i].subject 길이와 동일하게 출력한다.
4) 입력 템플릿의 key 구조를 바꾸지 말고, 빈 문자열로 되어 있는 value를 상황에 맞게 채워라.
5) 모든 값은 문자열로 채워라(숫자/불리언이 필요해도 문자열로).
6) representative_image_name(있는 경우)은 각 항목을 대표하는 사진을 위한 "단 하나의 이름"만 넣어라. (반드시 포함; 다른 항목의 이름과 겹치면 안된다;)
   - 사진으로 바로 찍을 수 있는 구체적인 사물(음식, 식재료, 영양제 알약/캡슐, 의료기기 등) 이름 1개를 넣는다. 예: "연어", "블루베리", "오메가3 캡슐", "혈압계"
   - "관리", "가이드", "상담", "식단", "그래프", "주의사항"처럼 추상적인 단어나 문장/긴 구절은 쓰지 않는다.
   - 항목마다 서로 다른 대상을 고르고, "영양제"처럼 너무 넓은 단어 대신 구체적인 성분/식품 이름을 쓴다.

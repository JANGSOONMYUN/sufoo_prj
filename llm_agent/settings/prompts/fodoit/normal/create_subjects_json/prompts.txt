사용자 질문: {question}

# 중요
- 사용자의 질문과 건강상태 그리고 섭취중인 약과 섭취중인 영양제 등 사용자의 개인 사항들을 고려하여 주제를 정한다.
- 초개인화를 위한 정보 전달이 목적
- 각 주제는 확실한 차이가 있어야 한다
- 눈에 띄도록 자극적인 문구 사용
# 필수 주제
    1. 사용자 질문에 대한 내용은 가장 처음 주제
    2. 사용자의 건강 정보를 바탕으로 추천하는 영양제 정보 (부작용에 대한 정보 포함; )
# 주제는 중복되면 안된다.
- 하나의 주제가 영양제를 다룬다면 그 다음 주제는 영양제가 아닌 다른 것에 대한 주제여야 한다

# 출력
- 사용자의 건강과 질문에 맞게 필요한 추가 주제를 string list 로 출력
